# vision-keeper

separate commission. This file exists so the apparatus's `files` manifest
already lists the role file and so a future commission can flesh it out
without changing the package's published shape.

When the runtime lands, this file will carry the agent's operational prompt
(role, principles, tool catalogue, dispatch wiring). Until then it intentionally
contains no executable instructions.
